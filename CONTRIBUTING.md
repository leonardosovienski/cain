# Contribuir

Instale `.[dev]`, execute `ruff check .` e `pytest -q` antes de enviar mudanças.
Novas decisões de pesquisa precisam de fonte, alternativa e condição de avaliação.
ADRs aceitos são preservados; revisão deve usar um ADR novo que supersede o anterior.

Os diretórios `evaluation/results/smoke-*` guardam demonstrações sintéticas.
Não use esses números como evidência da hipótese. Transcritos reais devem passar
pelo processo institucional definido para a pesquisa antes de qualquer publicação.
