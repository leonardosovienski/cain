# Material para avaliação cega

O identificador condition_id permanece estável por cenário entre sessões, permitindo comparar a mesma sonda longitudinalmente. A posição é randomizada em cada par. Não consulte os logs brutos nem a chave. Respostas podem sugerir sua condição; registre suspeitas de quebra do cegamento. Não atribua notas a respostas ausentes.
