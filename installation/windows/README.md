# Atalhos da instalação Windows existente

Estas são cópias versionadas dos três atalhos instalados em C:/CAIN.
Seu destino é a raiz da instalação, ao lado de projeto, .venv, dados e config; não devem ser executados dentro desta pasta de templates.

- ABRIR_CAIN.cmd: inicia/abre a interface principal em 127.0.0.1:8877.
- CAIN.cmd: encaminha argumentos para a CLI geral.
- CAIN_RESEARCH.cmd: encaminha argumentos para pesquisa com os bancos e política existentes.

Os caminhos derivam da localização do atalho e apontam para projeto, não para worktrees históricos.
A instalação/configuração do Python e de Ollama continua local. As cópias não instalam dependências nem substituem dados.
Veja o [mapa da instalação](../../docs/LOCAL_INSTALLATION.md).
