## Problema e mudança

A orientação anterior dizia para responder apenas ao pedido atual; o modelo reconhecia o histórico, mas interpretava “explique melhor” como falta de assunto. A nova orientação explicita que continuações desenvolvem o último assunto e que exemplos fictícios fornecem premissas válidas. Pedidos de texto exato devem preservar caracteres e não receber introdução. Um ajuste adicional exige JSON puro quando esse é o formato solicitado.

As regras são gerais; não contêm Alfa/Beta, NUVEM, respostas esperadas ou os dados dos testes. Perfil ativo, isolamento e limites de entrada continuam em vigor.
